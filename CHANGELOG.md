# Changelog

## 0.1.0

- Markdown retrieval with source lines, lexical ranking, RRF, and optional local embeddings.
- Bounded incident workflow with read-only tools, quote checks, explicit fallbacks, and SQLite traces.
- Time-scoped CSV statistics with timezone validation and empty-window handling.
- Optional HTTP and local Transformer model adapters.
- Loopback HTTP fault experiments and reproducible evaluation scripts.
- CLI, FastAPI, bundled example data, installable distributions, and CI checks.
