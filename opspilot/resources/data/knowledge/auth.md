# 鉴权排障手册（虚构）
## HTTP 401 与密钥
HTTP 401 表示身份认证未通过。检查 Authorization 请求头是否为 Bearer 加空格再加有效密钥，并确认密钥没有过期或被撤销。
不要把完整 API Key 发到工单或日志；定位时仅保留密钥末四位与 request_id。
## HTTP 403 与权限
HTTP 403 表示身份已识别但资源访问被禁止。核对项目角色、模型访问白名单和租户归属，申请最小必要权限。
重新生成密钥不能解决角色缺失导致的 403，需要项目管理员调整授权。
## 密钥轮换流程
轮换密钥时先创建新密钥并灰度更新客户端，确认新密钥调用成功后再撤销旧密钥。
演示环境的密钥最长有效期为30天，失效前3天发送提醒；该数值仅适用于本虚构系统。
