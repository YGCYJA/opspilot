# 对话记忆手册（虚构）
## 会话隔离
每个session_id独立保存对话上下文。只有同一会话的追问才可沿用最近一次服务名，不能读取其他用户会话作为记忆。
本地演示的session_id用于隔离上下文，不是身份认证凭据；公网部署前需要增加鉴权和授权。
## 记忆压缩
长对话只保留解决当前任务所需的摘要、已确认的实体与证据来源，不永久拼接全部历史消息。
摘要可能丢失细节，关键配置应重新查询知识库，不应把模型生成的记忆当作可靠事实。
## 数据删除
演示状态数据库可以通过停止服务后删除var目录中的runs.sqlite3来清空。正式系统需要按用户和租户实现可审计的数据删除接口。
保存运行轨迹前对Bearer凭据和常见密钥格式进行脱敏；正则脱敏有局限，不能视作完整DLP方案。
