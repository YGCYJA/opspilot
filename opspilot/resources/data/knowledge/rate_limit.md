# 频率限制手册（虚构）
## HTTP 429 限流
HTTP 429 表示触发请求频率或Token配额限制。先检查 Retry-After 响应头，再按指数退避并加入随机抖动重试，禁止无间隔循环重试。
演示网关对每个项目设置每分钟60次请求、每分钟20000个Token上限；这些是虚构配置。
## 并发控制
客户端使用信号量限制并发请求，批量任务采用队列排队。重试也必须计入并发与总请求预算，避免重试风暴。
当限流持续时减少批大小或降低并发，不应直接增加无限重试次数。
## 配额查询
配额是项目级而非个人级。观察剩余请求数和剩余Token两个维度，长文本请求可能在请求次数尚未耗尽时先触发Token限制。
配额耗尽不等于余额不足，先区分 429 与计费服务返回的 PAYMENT_REQUIRED。
