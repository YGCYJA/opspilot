# 超时与流式接口手册（虚构）
## HTTP 504 超时
HTTP 504 表示网关等待上游响应超时。对比首Token延迟、总推理耗时与网关 read_timeout，检查模型排队和输入上下文长度。
可先缩短输入并限制最大输出Token；不要仅增加客户端超时掩盖上游排队问题。
## SSE 流式中断
SSE 流式输出中途断开时检查代理缓冲、空闲超时与心跳保活。代理需关闭对 text/event-stream 的响应缓冲，并保持连接。
流式请求必须区分连接超时、读取超时与业务截止时间；收到部分输出后重试可能产生重复内容。
## 首Token延迟
首Token延迟 TTFT 是从请求发送到第一个输出Token到达的时间，通常包含排队与预填充计算时间。
总延迟还包含后续Token生成耗时。P95延迟升高时分别观察输入长度分布、队列长度与生成速度。
